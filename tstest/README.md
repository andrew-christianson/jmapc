# jmapc TypeScript Tests

This directory contains the test suite for the jmapc TypeScript library.

## Running Tests

```bash
npm test
```

## Test Coverage

```bash
npm run test:coverage
```

## Test Structure

- `client.test.ts` - Client class tests
- `api.test.ts` - API request/response tests
- `errors.test.ts` - Error handling tests
- `types.test.ts` - Type utility tests
- `ref.test.ts` - Reference system tests

More comprehensive tests matching the Python test suite should be added.
